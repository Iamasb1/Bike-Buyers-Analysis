# Bike Buyers Analysis

## Project Overview

This project explores customer demographics and bicycle purchasing behaviour using Microsoft Excel.

The goal is to examine customer characteristics and identify patterns that may help explain which customers purchase bicycles.

## Tools Used

* Microsoft Excel

## Skills Demonstrated

* Data cleaning and preparation
* Data standardisation
* Excel formulas and conditional logic
* Age-group categorisation
* Pivot table analysis
* Data visualisation and dashboard development

## Project Workflow

### 1. Data Preparation

Reviewed and prepared the customer dataset for analysis, including standardising selected categorical values and creating age groups.

### 2. Data Analysis

Used pivot tables to explore relationships between customer characteristics and bicycle purchasing behaviour.

### 3. Dashboard Development

Created an Excel dashboard to present the analysis visually and make the information easier to interpret.

## Dataset

The dataset contains customer information, including:

* Gender and marital status
* Income
* Number of children
* Education and occupation
* Homeownership
* Number of cars
* Commute distance
* Region and age
* Bicycle purchase status
